# Насадка-имя на карандаш

Объёмное имя, которое надевается на карандаш или ручку: буквы слиты в одно тело,
вдоль него проходит сквозной канал под грань карандаша.

За основу взята модель MakerWorld
[#2374615 «Nome infilabile matita parametrico»](https://makerworld.com/ru/models/2374615-customizable-parametric-pencil-slide-on-name).
Её онлайн-конструктор заменён собственным генератором: имена считаются локально,
пакетом, без веб-интерфейса и без расхода кредитов.

## Структура

| Папка | Что внутри |
|---|---|
| `Заготовки/` | STL и 3MF, скачанные из конструктора MakerWorld — эталон для сверки |
| `Скрипты/` | генератор (`generate_names.py`), шаблон OpenSCAD, рендер превью |
| `Готовые модели/` | результат генерации: STL + сгенерированный `.scad` рядом |
| `fonts/` | шрифт Shantell Sans ExtraBold (SIL OFL 1.1, есть кириллица) |

## Быстрый старт

Нужны OpenSCAD и Python с `fontTools` (для превью — ещё `matplotlib`).

```bash
python "Скрипты/generate_names.py" ДИМА ИЛЬЯ ЯСМИНА --hole 7.8
```

Список имён можно держать в файле:

```bash
python "Скрипты/generate_names.py" --file "Скрипты/names.txt" --hole 7.8
```

Картинка для проверки перед печатью:

```bash
python "Скрипты/preview.py" "Готовые модели/ДИМА_7.8.stl" -o превью.png
```

## Параметры

Имена конструктора MakerWorld и соответствующие ключи генератора:

| MakerWorld | Ключ | По умолчанию | Смысл |
|---|---|---|---|
| `nome testo` | позиционный аргумент | — | текст имени |
| `nome_font` | `--font` | `ShantellSans-ExtraBold.ttf` | файл шрифта из `fonts/` |
| `dimensione testo` | `--size` | `12` | размер шрифта |
| `altezza nome` | `--height` | `10` | базовая высота букв, мм |
| `diametro foro` | `--hole` | `7.8` | диаметр канала под карандаш, мм |
| `modalita` | `--mode` | `zigzag` | `zigzag` или `flat` |
| `zigzag su` | `--up` | `0.9` | насколько выше базовой чётные буквы |
| `zigzag giu` | `--down` | `0.25` | насколько ниже базовой нечётные буквы |
| — | `--spacing` | `0.84` | множитель шага между буквами |

По умолчанию имя переводится в ВЕРХНИЙ РЕГИСТР (`--keep-case` отключает).

## Как устроена геометрия

Разобрано обмером эталонного `Заготовки/ДИМА_7.8.stl`:

* все буквы стоят на общем дне `Z = 0` — печатается без поддержек;
* **«зигзаг» — это разная ВЫСОТА букв, а не сдвиг по вертикали:**
  чётные `10 + 0.9 = 10.9` мм, нечётные `10 − 0.25 = 9.75` мм
  (в эталоне ровно две плоскости верха: `10.900` и `9.750`);
* канал под карандаш — цилиндр вдоль оси X, ось на `Z = body_h / 2 = 5.0`,
  диаметр точно равен заявленному (`7.800` и `7.400` в двух версиях эталона);
* текст центрирован по чернильному габариту, ось канала проходит по `Y = 0`.

Буквы одной высоты объединяются в 2D и выдавливаются одним `linear_extrude`.
Объединять N отдельных объёмных букв в 3D CGAL считает примерно вдвое дольше
при том же результате.

## Два неочевидных момента

**Шрифт.** OpenSCAD ищет шрифты только через fontconfig: `C:\Windows\Fonts`,
`%LOCALAPPDATA%\fonts` и `~/.fonts`. Папку проекта и `OPENSCADPATH` он для
шрифтов **не** смотрит, поэтому генератор сам кладёт копию `.ttf` в `~/.fonts`
— без прав администратора и без записи в реестр.

**Масштаб.** `text(size=N)` в OpenSCAD — это не размер em. Для Shantell Sans
одна единица `size` равна 720 font-units, а не 1000. Коэффициент зависит от
шрифта, поэтому генератор измеряет его один раз пробным рендером глифа и
кеширует в `Скрипты/.font_calibration.json`.

## Проверка связности

Если буквы не соприкасаются, деталь распадётся на куски. После генерации
считается число связных компонент меша; при значении больше 1 генератор
сам уменьшает `--spacing` шагами по `0.02` и пересобирает модель.
Черновые прогоны идут на низком `$fn` (быстро) — тессиляция там срезает дуги
внутрь, поэтому слипшееся на черновике гарантированно слипнется на чистовом.

Итог сверки с эталонами MakerWorld (габариты, мм):

| Имя | Генератор | Эталон |
|---|---|---|
| ДИМА | 49.21 × 15.23 × 10.90 | 49.30 × 15.08 × 10.90 |
| ИЛЬЯ | 37.84 × 12.27 × 10.90 | 37.28 × 12.18 × 10.90 |
| ЯСМИНА | 63.83 × 12.18 × 10.90 | 63.63 × 12.18 × 10.90 |

Расхождение до 1.5% — генератор не применяет кернинг (GPOS), который
использует конструктор MakerWorld. На посадку на карандаш это не влияет:
диаметр канала выдерживается точно.

## Печать

Пластик PLA. Печатать как есть, плоским дном на стол, без поддержек.
Для двухцветного варианта модель делится по высоте — верх зигзага
выступает над основной массой на 0.9 мм.
